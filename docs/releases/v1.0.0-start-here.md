# Lenovo Legion Adapter Warning — Version 1.0.0

**Regular release for the tested Legion 5 Pro 16ACH6H / 82JQ, BIOS GKCN65WW. Secure Boot must remain disabled for this unsigned release.**

This package suppresses the low-wattage AC adapter startup interruption using the proven V4 helper. The product release is **1.0.0**; executable filenames, logs, and saved driver descriptions retain **v4** to preserve the already tested implementation and installation paths.

> The connected AC adapter has a lower wattage than the recommended AC adapter which was shipped with the system. To use AC power, please connect the AC adapter which was shipped with the system. Press Esc to continue.

## Pick your starting point

| Your situation | What to do |
| --- | --- |
| Already starts normally from the internal drive without the helper USB | No reinstall or binary replacement needed. Your working V4 helper is the Version 1.0.0 helper. |
| New installation | Confirm model and BIOS in `msinfo32`, then follow **USB-WALKTHROUGH.md**. Complete the diagnostic, manual test, and automatic USB comparison on your own machine first. |
| Automatic USB setup already works | Follow **INTERNAL_SETUP/READ-ME-FIRST.md** to move it to the internal drive. Keep the setup USB for recovery. |
| Ready to investigate Secure Boot | Read **SIGNING-WALKTHROUGH.md**. The small separate inventory ZIP on the release page provides the Windows scripts. |

Extract the package fully. For USB setup, copy only the contents of the stage folder specified by the guide to a suitable FAT32 USB. Do not copy all stages together: each contains a different `EFI/BOOT/BOOTX64.EFI`. Formatting erases a USB; back it up first if formatting is required.

New users still need the staged checks. A regular release does not prove compatibility with every laptop bearing the same model name. Do not update or downgrade BIOS solely to match this project without a separate assessment.

## Evidence and limits

One owner's GKCN65WW machine demonstrated warning suppression with the helper USB inserted / removed / reinserted, followed by reported successful internal startup without USB or F12. Mouse and thumb-drive operation were also reported. A full internal-run log, long-term reliability, other BIOS versions, docks, and complete physical internal recovery remain unverified.

The helper changes one byte in the warning callback in RAM each boot. It does not flash the BIOS chip, raise USB-C wattage, or remove charging/performance limits. Pre-Windows code and EFI filesystem changes can still disrupt startup. Keep the encryption recovery key private and available before boot-configuration changes. Removing the USB does not disable an internal installation; use the guide's specific disable/removal procedure.

## Verify your download

The release includes **SHA256SUMS-v1.0.0.txt** for both download ZIPs. In Windows PowerShell, with the ZIP in the current folder:

```powershell
Get-FileHash -Algorithm SHA256 '.\Lenovo-Legion-Adapter-Warning-v1.0.0.zip'
```

Compare the entire hash to that ZIP's line in the release checksum file. Each extracted package also contains its own **SHA256SUMS.txt** listing the selected contents.
