# Version 1.0.0 — warning-free startup without a helper USB

The first regular release of Lenovo Legion Adapter Warning, for the tested **Legion 5 Pro 16ACH6H / 82JQ with BIOS GKCN65WW**. This release is not a prerelease.

> The connected AC adapter has a lower wattage than the recommended AC adapter which was shipped with the system. To use AC power, please connect the AC adapter which was shipped with the system. Press Esc to continue.

## Downloads

- **Lenovo-Legion-Adapter-Warning-v1.0.0.zip** — complete staged USB setup, internal installation/recovery files, updated guides, and checksums.
- **Lenovo-Secure-Boot-Inventory-v1.0.0.zip** — small Windows read-only preparation package for the separate signing project, including the detailed walkthrough and risks. It contains no EFI installer or enrollment commands.
- **SHA256SUMS-v1.0.0.txt** — checksums for both ZIPs.

Download the named ZIP you need under Assets. The automatically generated Source code archives are for source browsing/development.

## Already running the internal V4 setup?

**No reinstall needed.** Version 1.0.0 uses the exact same tested V4 executable. The internal filename, driver entry, and original binaries retain their V4 identifiers. Existing published prerelease assets are preserved.

## What has been demonstrated

- Reviewed physical diagnostic/manual/automatic results and reported USB inserted / removed / reinserted warning comparison.
- Reported normal internal-drive startup without a helper USB or F12.
- Mouse and thumb-drive operation reported working after internal startup.
- Byte-identical helper rebuilds, 33 host fault-injection cases, and isolated deployment checks.

These observations cover one machine/firmware combination. A full internal-run log, long-term reliability, other models/firmware, broader dock behavior, and complete physical internal recovery are not established. New installations should follow the included diagnostic-first walkthrough.

## Secure Boot status

**This regular release remains unsigned and requires Secure Boot disabled.** Offline signing and disposable Secure Boot VM admission have passed, but Lenovo trust enrollment and Secure Boot-enabled warning suppression are not yet validated. Do not re-enable Secure Boot expecting the current helper to keep working.

For an existing internal installation, the small inventory ZIP provides read-only preparation: extract it, follow the current [online walkthrough](../../signing/WALKTHROUGH.md), run `Read-SecureBootState.cmd` as administrator in Windows, and retain the results locally. No maintainer submission is required. The published ZIP retains its original guide text; use the current online guide for updated instructions. Keep trust exports and encryption recovery keys off public issues.

The helper changes the warning callback in RAM each boot; it does not flash the BIOS, increase USB-C power, or remove charger/performance limits. It remains powerful pre-Windows code. Read the installation/recovery guide before a new setup and the signing walkthrough before any trust changes.
