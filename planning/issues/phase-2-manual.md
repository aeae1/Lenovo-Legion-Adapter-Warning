# Validate the manual RAM patch and permission restoration on the laptop

Depends on review of the Phase 1 diagnostic.

Use the existing V4 manual helper and normal Lenovo charger only when the diagnostic supports this stage. Follow the existing walkthrough. Record identity, patch result, current page permissions, any permission transition/restoration, and behavior after a full power-off.

Completion: evidence that the intended one-byte RAM change was verified, and that any required permission restoration was verified, or a documented refusal/error with no further automatic installation. A late manual success proves mechanics only; it does not prove early automatic execution. If firmware restoration fails, record that explicitly and use the documented recovery path.
